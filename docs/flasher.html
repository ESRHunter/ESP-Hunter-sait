Инструкция

  • 1. Подключите ESP32-S3 к компьютеру через USB.
  • 2. Нажмите «Подключиться» и выберите COM-порт.
  • 3. Загрузите прошивку (с GitHub или локально).
  • 4. Нажмите «Прошить» и дождитесь завершения.
  • 5. После прошивки устройство перезагрузится автоматически.

Внимание: Прошивка через Web Serial работает в Chrome / Edge / Opera.
